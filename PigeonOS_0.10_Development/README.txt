PigeonOS 0.10 Development
========================

Active development lives here:

  Pigeon/                 Runnable app (Mac + Pi scripts + pigeonAssets)
  PigeonOS_0.10_GFX/      Design sources for this version (local duplicate of Pigeon_GFX; not in Pi tarball)
  testingEnvironments/    Standalone UI / widget previews
  README.md               Glossary (views, assets, shortcuts, modules)

Mac Desktop shortcuts (from installer/setup_desktop_launchers.sh):
  ~/Desktop/Pigeon (experiment).command  — this tree / branch PigeonOS_0.10
  ~/Desktop/Pigeon (0.10).command        — same as experiment (explicit 0.10 name)
  ~/Desktop/Pigeon (main).command        — ~/Desktop/Pigeon-main release worktree

Mac: open Pigeon/installer and run run_pigeon_0_10.command
Pi:  see Pigeon/installer/START-HERE.txt

Settings and credentials stay in ~/.pigeon_0_6 (shared with earlier installs).

The previous 0.9 development tree + GFX snapshot is archived at:
  ../Archive/PigeonOS_0.9_Development/
  ../Archive/PigeonOS_0.9_Development/PigeonOS_0.9_GFX/

Do not link future builds to Archive/ or to the root Pigeon_GFX/ tree
(prefer PigeonOS_0.10_GFX/ for 0.10 design work).
