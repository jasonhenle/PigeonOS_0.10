PigeonOS 0.10 Development
========================

Active development lives here:

  Pigeon/                 Runnable app (Mac + Pi scripts + pigeonAssets)
  PigeonOS_0.10_GFX/       Design sources for this version (local; not in Pi tarball)
  testingEnvironments/    Standalone UI / widget previews
  README.md               Glossary (views, assets, shortcuts, modules)

Mac: open Pigeon/installer and run run_pigeon_0_10.command (or run_pigeon_0_8.command)
Pi:  see Pigeon/installer/START-HERE.txt

Settings and credentials stay in ~/.pigeon_0_6 (shared with earlier installs).

The previous 0.9 development tree is archived at:
  ../Archive/PigeonOS_0.9_Development/

Do not link future builds to Archive/ or to the root Pigeon_GFX/ tree.
